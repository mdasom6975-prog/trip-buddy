표현과 연령 필터는 화면에 보이는 선택지를 필터링한다. 필터만 바꿔도 이전에 선택한 캐릭터를 임의 교체하지 않으며, 실제 선택한 캐릭터는 큰 미리보기와 이름으로 표시한다. 선택 변경은 카드 클릭으로 확정한다.

현재는 완성된 6종 선택형이며 헤어·피부색·옷의 자유 조합은 제공하지 않는다. 그림체는 부드러운 3D 일러스트로 유지한다. 실제 3D 모델·리깅·자유 회전은 없다.

## 파일과 표시

`frontend/public/characters`의 main(3×2), senior(2×1), extra(2×2) 시트에 캐릭터별 기본·안내 포즈를 저장한다. CharacterArt 컴포넌트가 정사각형 셀로 표시하므로 비율이 늘어나지 않는다. 기존 시안을 보존하기 위해 원본 이미지는 수정하지 않았다. 투명 배경 및 개별 파일 분리는 후속 최적화 항목이다.

## 적용

- 스튜디오: 기본 포즈, 닉네임 미리보기
- 홈: 선택한 캐릭터와 인사
- 대화: 기본 인사, 진행·답변의 안내 포즈
- 결과 대기: 안내 포즈와 빈 상태

노드별 별도 포즈 4종을 모두 제작한 상태는 아니다. 현재 2개 포즈를 UI 상태에 맞춰 사용한다. 캐릭터 외형으로 사용자 실제 성별·나이·보행 능력을 추정하지 않는다. 움직임은 진행 스피너 외에 없으며 동작 줄이기 설정을 존중한다.
