## 고친 부분

- 웹앱 엔진이 Claude를 고정 사용하던 코드를 수정했다.
- 실제 제공자는 `TRIPBUDDY_PROVIDER`를 명시하면 해당 값, 없으면 원본 `config.LLM_PROVIDER`를 따른다.
- 보고하는 제공자·모델 이름도 실제 선택값을 따른다.
- 토큰 사용량을 실제 응답에서 수집하도록 연결했다. 오류 시 빈 사용량을 0비용으로 단정하지 않는다.
- 원본 프로젝트와 비밀 파일은 수정하지 않았다.

## 현재 상태와 다음 결정

이번 검증은 **실제 모델 호출이 코스 생성까지 성공했다는 증거가 아니다.** 실제 코스·지도·내보내기·지정 칸 수정의 실데이터 검증은 아직 대기 중이다. 체험 모드의 자동·브라우저 검증 결과와 구분한다.

사용자에게 다음 선택을 요청했다.

선택 전에는 추가 유료 호출을 하지 않는다. 실행 데이터와 실패 요약은 git 제외 `data/live-validation/`에 저장했다.
